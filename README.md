# Brain-Tumor-MRI-Image-Classification
End-to-end deep learning solution for automated brain MRI classification across four categories (Glioma, Meningioma, Pituitary, No Tumor). Utilizes a fine-tuned MobileNetV2 transfer learning model, comprehensive evaluation metrics, and an interactive Streamlit web application for real-time diagnostics.

App Demo: https://brain-tumor-mri-image-classification-6fv7mstjslwfymytzfhkjv.streamlit.app/
